## Concept
- VR escape game.
- The aim of the game is to help people with their administrative tasks by making the world of paperwork less dramatic.

## Features
- Interact with cards.
- Print A4 sheets.
- Score baskets with a ball of paper (reduces stress !).
- Stamp a document, stamp a table, STAMP EVERYTHING !
- Place folders in the letter box.

## Technic
- Engine : Unity 6000.00.33f1
- Lib : XR Interaction Toolkit
- All assets come from Unity [Asset store](https://assetstore.unity.com) and [Sketchfab](https://sketchfab.com).
- In order to reduce cybersickness, we added the tunneling, and restrict some movements.
- During the game, some data is stored in a file called "Telemetry.csv", which is located on the desktop.
